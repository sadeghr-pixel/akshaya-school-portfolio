# Akshaya National Public School — Web Development Portfolio

A Django school website project by Mohammad Sadegh Rezaeitelzali. This repository presents the project while keeping its implementation and school data private.

## Project features

The recovered project includes routes and application code for:

- Home, about, contact, and gallery pages
- Admissions forms
- A fee portal
- Admission and fee payment order creation with Razorpay integration
- Payment callbacks and result pages
- Admission form downloads
- Django administration and a health endpoint

## Technology

Python, Django, PostgreSQL, HTML templates, WhiteNoise, Razorpay, and Docker Compose.

## Current status

The original website is currently offline. Project files were recovered from the folder linked to its Docker container and copied to a separate local folder. The copy was verified against the source. School workflows and payment processing have not been tested as part of this portfolio review.

## Privacy

This public repository contains documentation only. Application code, student records, dates of birth, payment details, credentials, database contents, and deployment settings are excluded.

## Professional focus

Junior Django / web development, IT support, Ubuntu VPS administration, and ongoing DevOps learning.
